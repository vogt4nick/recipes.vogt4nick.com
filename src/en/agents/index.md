# Agents

Help the user satisfy their use case. Each has an
[agent prompt](choose-a-weeknight-dinner.md) for use with an AI assistant.

1. **[Unplanned weeknight dinner](choose-a-weeknight-dinner.md).** Given I just
    got out of work, I want to decide what I'm making for dinner; preferably I
    would choose from a pre-selected list of recipes.
2. **[Meal planning](make-a-meal-plan.md).** Given I have a normal few days
    ahead, I want to make a meal plan.
3. **[Find a recipe](find-a-recipe.md).** Given I have a specific idea in mind,
    I want to find a suitable recipe or recipes.
4. **[Grocery shopping](make-a-grocery-list.md).** Given I know my meal plan, I
    want to make my grocery list.
